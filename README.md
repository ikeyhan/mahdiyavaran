# اتم ۳۱۳ — Atom 313

بازارگاه دیجیتال کامل فارسی (RTL): فروشگاه چندفروشنده‌ای، دفاتر خدمات محلات با اعتبارسنجی کد ملی و گفتگو، حساب خریدار، سبد خرید و ثبت سفارش، پیگیری سفارش، بلاگ، و پنل مدیریت کامل با ۳۶ بخش.

پروژه در **دو حالت** اجرا می‌شود و همهٔ بخش‌ها در هر دو حالت کار می‌کنند:

| حالت | اجرا | داده‌ها |
|---|---|---|
| **سرور واقعی (پیشنهادی برای راه‌اندازی)** | `node backend/server.js` | پایگاه دادهٔ SQLite روی سرور، مشترک بین همهٔ کاربران |
| **حالت HTML (بدون سرور)** | باز کردن فایل‌ها یا هر هاست استاتیک | پایگاه دادهٔ همان مرورگر (برای تست و دمو) |

سایت خودش تشخیص می‌دهد سرور در دسترس است یا نه (`/api/health`)؛ اگر نبود، موتور `assets/js/demo-db.js` با همان قوانین سرور (نقش‌ها، مالکیت، کلمات ممنوعه، کد ملی، کد تخفیف، …) پاسخ می‌دهد.

## راه‌اندازی روی هاست و دامنه (سرور واقعی)

نیازمند Node.js نسخهٔ ۱۸ به بالا (هاست‌های Node در cPanel/DirectAdmin، VPS یا سرویس‌هایی مثل لیارا و آروان).

```bash
cd backend
cp .env.example .env        # مقادیر را ویرایش کنید (بخش بعد)
npm install --omit=dev
npm start                   # سایت:  http://دامنه/      پنل: http://دامنه/adminpanel/
```

یک سرور همه‌چیز را سرو می‌کند (سایت + پنل + API)، پس دامنه را مستقیم به پورت برنامه (یا از طریق Nginx/Apache به‌صورت reverse proxy) وصل کنید. برای اجرای دائمی از `pm2 start backend/server.js --name atom313` استفاده کنید. HTTPS را روی هاست/Nginx فعال کنید.

### چک‌لیست پیش از انتشار عمومی

1. در `backend/.env` مقدار `ADMIN_PASSWORD` را **پیش از اولین اجرا** به رمز قوی تغییر دهید (یا بعد از ورود از «امنیت و دسترسی» عوض کنید).
2. `SEED_DEMO=0` بگذارید تا حساب‌های نمونه (atra، daftar، reza، samira) ساخته نشوند؛ یا در پنل روی دکمهٔ «غیرفعال‌سازی حساب‌های نمونه» در نوار هشدار بزنید.
3. `JWT_SECRET` را خالی بگذارید تا سرور یک کلید تصادفی امن بسازد (`backend/data/jwt-secret`)، یا خودتان یک مقدار ۴۸ بایتی تصادفی بگذارید.
4. از پنل › تنظیمات سایت: نام، شماره تماس، آدرس، شبکه‌های اجتماعی، هزینهٔ ارسال و سقف ارسال رایگان را وارد کنید (در فوتر و سبد خرید اعمال می‌شود).
5. از پوشهٔ `backend/data/` (پایگاه داده) و `backend/uploads/` (تصاویر) به‌طور منظم پشتیبان بگیرید. پنل › پشتیبان‌گیری هم خروجی JSON کامل می‌دهد.

> پرداخت آنلاین هنوز به درگاه متصل نیست: سفارش‌ها ثبت می‌شوند، مدیر و فروشنده آن‌ها را می‌بینند و هماهنگی پرداخت/ارسال تلفنی انجام می‌شود.

## تست سریع در حالت HTML

فایل `index.html` را مستقیم باز کنید یا پوشه را روی هر هاست استاتیک بگذارید. حساب‌های نمونه:

| نقش | ورود | نام کاربری / رمز |
|---|---|---|
| مدیر کل | `adminpanel/index.html` | `admin` / `atom313@` |
| فروشنده | `login.html` | `atra` / `atra1234` |
| دفتر محله | `login.html` | `daftar` / `daftar1234` |
| خریدار | `login.html` › ثبت‌نام خریدار | حساب جدید بسازید |

کد تخفیف نمونه: `ATOM20` و `ATOM40`. دکمهٔ «بازنشانی دادهٔ دمو» در پنل، داده‌های مرورگر را به حالت اولیه برمی‌گرداند. برای به‌روزکردن دادهٔ اولیهٔ حالت HTML از روی پایگاه دادهٔ سرور: `node backend/tools/export-demo-seed.js`.

## معماری فایل‌ها

```
backend/                 → Express + SQLite + JWT (server.js، src/routes/*، tools/)
assets/js/demo-db.js     → موتور حالت HTML (آینهٔ کامل API سرور در مرورگر)
assets/js/demo-seed.js   → دادهٔ اولیهٔ حالت HTML (تولید خودکار از seed سرور)
assets/js/site-auth.js   → کلاینت API سایت (ورود، سفارش، پنل‌ها)
assets/js/main.js        → رابط سایت: تم، منو، سبد خرید، علاقه‌مندی، جستجو، ویجت پشتیبانی
assets/js/catalog.js · product.js · account.js · seller-panel.js · stores.js · pages-extra.js
adminpanel/api.js · pages.js · activate.js → کلاینت API، اتصال داده‌ها، فعال‌ساز همهٔ دکمه‌ها
```

### امنیت

- رمزها با bcrypt، ورود با JWT، قفل پس از تلاش‌های ناموفق و محدودیت نرخ درخواست.
- فروشنده و دفتر فقط دادهٔ خودشان را می‌بینند؛ دادهٔ مشتریان، سفارش‌ها، تنظیمات و لاگ‌ها فقط برای کارکنان پنل است.
- کلید API هوش مصنوعی هرگز به مرورگر ارسال نمی‌شود؛ آپلود SVG مسدود است؛ CORS فقط same-origin.
- قیمت سفارش و کد تخفیف سمت سرور دوباره محاسبه می‌شود.

## هویت بصری

### لوگو
نماد لوگو یک **اتم سبز** است: هسته‌ی مرکزی به‌همراه سه مدار الکترون، نماد علم، شبکه و اتصال — متناسب با مفهوم «ستاد» و فضای دیجیتال و علمی. لوگو در سه نسخه ارائه شده: رنگی (`logo-mark.svg`)، تک‌رنگ برای هر پس‌زمینه (`logo-mark-mono.svg` با `currentColor`)، و لوگوی کامل با وردمارک (`logo-full.svg`). هر سه SVG برداری و در هر اندازه (فاوآیکون تا بیلبورد) قابل‌استفاده‌اند و در هر دو حالت روشن و تاریک کار می‌کنند.

### رنگ — سبز و سفید
سیستم رنگی فلت با پایه‌ی سفید/خاکستری روشن و لهجه‌ی سبز برند:

| نقش | متغیر CSS | مقدار (روشن) |
|---|---|---|
| پس‌زمینه صفحه | `--bg` | `#F4F6F5` |
| سطح کارت | `--surface` | `#FFFFFF` |
| کادر/بوردر | `--border` | `#E6E9E7` |
| متن اصلی | `--text-1` | `#1A1D1B` |
| سبز برند (اصلی) | `--green-600` | `#149B3E` |
| سبز روشن | `--green-500` | `#1BB24B` |
| قرمز تخفیف | `--red-500` | `#E5484D` |
| کهربایی (ستاره‌ی امتیاز) | `--gold-500` | `#F0A020` |

حالت تاریک با `html[data-theme="dark"]` کاملاً بازتعریف شده (زغالی `#101311`، سطوح `#171A18`) و لهجه‌ی سبز روی آن می‌درخشد؛ با کلید تم در هدر (ذخیره در `localStorage`) قابل‌جابه‌جایی است.

### تایپوگرافی
فونت اصلی **Yekan Bakh** (فونت مورد استفاده در Basalam) در استک قرار دارد و در صورت نصب‌بودن روی سیستم/سرور به‌صورت خودکار استفاده می‌شود. به‌عنوان جایگزین رایگان و هم‌خانواده از نظر سبک، **Vazirmatn** (از Google Fonts) بارگذاری شده تا تجربه‌ی بصری همیشه یکدست و حرفه‌ای بماند:

```css
--font-fa: 'Yekan Bakh','YekanBakh','Vazirmatn','IRANSansX',Tahoma,sans-serif;
```

> برای استفاده‌ی رسمی از Yekan Bakh، فایل webfont لایسنس‌دار آن را به `assets/fonts` اضافه کرده و با `@font-face` در ابتدای `style.css` تعریف کنید؛ استک فونت به‌طور خودکار آن را در اولویت قرار می‌دهد.

### سبک بصری — فلت
طراحی کاملاً **فلت** است (نئومورفیسم حذف شده): کارت‌های سفید با کادر ۱ پیکسلی و سایه‌ی بسیار ملایم، گوشه‌های گرد، دکمه‌های تخت سبز، و هدر دو‌ردیفه به سبک Basalam (ردیف بالا: لوگو + نوار جستجوی برجسته + حساب/سبد؛ ردیف پایین: نوار دسته‌بندی‌ها).

## یادداشت فنی

- سایت کامل RTL و بهینه برای فارسی است (`dir="rtl"` روی `<html>`).
- انیمیشن‌ها سبک و مبتنی بر `IntersectionObserver` (کلاس `.reveal`) و CSS transitions هستند؛ هیچ کتابخانهٔ خارجی JS در فرانت‌اند استفاده نشده.
