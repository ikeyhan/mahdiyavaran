# ستاد مهدی‌آوران — Setad Mahdiavaran

بازارگاه دیجیتال پرمیوم؛ یک وب‌سایت کامل و آماده‌ی تولید با هویت بصری اختصاصی، طراحی‌شده با سبک **Minimal Neumorphism (Soft UI)**، برای اتصال کسب‌وکارها، فروشندگان، ارائه‌دهندگان خدمات و مشتریان در یک اکوسیستم امن و مدرن — با الهام از تجربه‌ی Basalam و فلسفه‌ی طراحی Apple.

این پروژه یک سایت استاتیک HTML/CSS/JS خالص است؛ بدون فریم‌ورک، بدون فرآیند build، آماده برای هاست روی هر سرویس استاتیک (GitHub Pages, Netlify, Vercel, Nginx و ...).

---

## پیش‌نمایش سریع

```bash
# از ریشه‌ی پروژه
python3 -m http.server 8080
# سپس مرورگر را باز کنید:
http://localhost:8080/index.html
```

> باز کردن مستقیم فایل‌ها با دابل‌کلیک (`file://`) به دلیل بارگذاری فونت و برخی محدودیت‌های مرورگر توصیه نمی‌شود؛ همیشه از یک سرور محلی استفاده کنید.

## معماری فایل‌ها

```
assets/
  css/style.css      → کل دیزاین‌سیستم (توکن‌ها، تایپوگرافی، کامپوننت‌ها، ریسپانسیو)
  js/main.js          → تم روشن/تاریک، منوی موبایل، تب‌ها، ویش‌لیست، شمارنده‌ها، اسکرول
  svg/logo-mark.svg   → نماد لوگو (رنگی)
  svg/logo-mark-mono.svg → نماد تک‌رنگ (currentColor) برای حالت‌های خاص
  svg/logo-full.svg   → لوگوی کامل (نماد + وردمارک فارسی + انگلیسی)
  svg/icons.svg       → اسپرایت کامل آیکون‌های SVG (به‌صورت inline در هر صفحه تزریق شده)
```

آیکون‌ها به‌صورت اسپرایت `<symbol>` در ابتدای `<body>` هر صفحه inline شده‌اند و با `<use href="#icon-name">` فراخوانی می‌شوند — این روش سریع‌ترین و سازگارترین شیوه‌ی استفاده از آیکون SVG در تمام مرورگرهاست (بدون وابستگی به fetch یا فایل خارجی).

## هویت بصری

### لوگو
نماد لوگو ترکیبی از دو مفهوم است:
- **قوس طلایی** (رنگ `--gold-500` → `--gold-300`): یادآور دروازه‌ی بازار سنتی ایرانی و مفهوم اعتماد و اصالت.
- **مسیر صعودی با گره‌های متصل** (رنگ `--indigo-500` → `--teal-400`): نماد شبکه، اتصال فروشنده-خریدار و رشد کسب‌وکار دیجیتال.

سه نسخه از لوگو ارائه شده: رنگی (`logo-mark.svg`)، تک‌رنگ برای هر پس‌زمینه (`logo-mark-mono.svg` با `currentColor`)، و لوگوی کامل با وردمارک (`logo-full.svg`). هر سه به‌صورت SVG برداری و قابل‌استفاده در هر اندازه (فاوآیکون تا بیلبورد) هستند.

### رنگ
سیستم رنگی بر پایه‌ی خاکستری/سفید نرم (نئومورفیسم) با دو رنگ لهجه‌ای پرمیوم:

| نقش | متغیر CSS | مقدار (روشن) |
|---|---|---|
| پس‌زمینه | `--bg` | `#EEF0F3` |
| سطح کارت | `--surface` | `#EEF0F3` |
| متن اصلی | `--text-1` | `#1E2230` |
| لهجه طلایی (اعتماد/تجارت) | `--gold-500` | `#B8863A` |
| لهجه ایندیگو/تیل (تکنولوژی) | `--indigo-500` / `--teal-400` | `#3E52D9` / `#25C2B0` |

حالت تاریک با `html[data-theme="dark"]` کاملاً بازتعریف شده (خاکستری زغالی `#17181C`، سطوح `#1B1D22` تا `#24262D`) و با کلید تم در هدر (ذخیره در `localStorage`) قابل‌جابه‌جایی است.

### تایپوگرافی
فونت اصلی **Yekan Bakh** در نظر گرفته شده (فونت تجاری، از طریق `font.ir` قابل تهیه)؛ در صورت نصب‌بودن روی سیستم کاربر به‌صورت خودکار استفاده می‌شود (`local()`). به‌عنوان جایگزین متن‌باز و هم‌خانواده از نظر سبک، **Vazirmatn** (از Google Fonts) بارگذاری شده تا در نبود فونت اصلی، تجربه‌ی بصری همچنان پرمیوم و یکدست بماند:

```css
--font-fa: 'YekanBakh','Vazirmatn','IRANSansX',Tahoma,sans-serif;
```

### سایه‌های نئومورفیک
سه سطح اصلی تعریف شده: `--shadow-raised-sm/--shadow-raised/--shadow-raised-lg` برای عناصر برجسته، و `--shadow-inset/--shadow-inset-sm` برای فرورفته (اینپوت‌ها، نوار جستجو، تب‌بار). این سایه‌ها در حالت تاریک به‌طور خودکار با کنتراست مناسب بازتعریف می‌شوند.

## کامپوننت‌ها

طراحی‌شده در `assets/css/style.css` و آماده برای استفاده در هر صفحه‌ی جدید:

دکمه‌ها (`.btn`, `.btn-primary`, `.btn-gold`, `.btn-ghost`, `.btn-icon`) · کارت‌های نئومورفیک (`.surface`, `.surface-inset`) · کارت محصول (`.prod-card`) · کارت فروشنده (`.seller-card`) · تب‌بار (`.tabbar`) · فرم‌ها (`.field`) · جدول داشبورد (`.dtable`) · نشان وضعیت (`.status-chip`) · بنر تبلیغاتی (`.banner`) · حالت خالی/خطا (`.state-block`) · کشوی موبایل (`.mobile-drawer`) · و ده‌ها کلاس کمکی دیگر.

همه‌ی کامپوننت‌ها **موبایل‌فرست و کاملاً ریسپانسیو** هستند (breakpoint در ۱۱۸۰px، ۹۸۰px و ۶۴۰px).

## یادداشت فنی

- سایت به‌صورت کامل RTL و بهینه برای فارسی نوشته شده (`dir="rtl"` روی `<html>`).
- انیمیشن‌ها سبک و مبتنی بر `IntersectionObserver` (کلاس `.reveal`) و CSS transitions هستند؛ هیچ کتابخانه‌ی خارجی JS استفاده نشده.
- این یک دمو/فرانت‌اند طراحی محور است؛ فرم‌ها، پرداخت و داده‌ها نمایشی (mock) هستند و برای اتصال به بک‌اند واقعی نیاز به توسعه‌ی API دارند.
