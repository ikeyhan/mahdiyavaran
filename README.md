# ستاد مهدی‌یاوران — Setad Mahdiyavaran

بازارگاه دیجیتال؛ یک وب‌سایت مارکت‌پلیس کامل و آماده‌ی تولید با هویت بصری اختصاصی، طراحی‌شده با سبک **فلت و کارت‌محور (با الهام از Basalam)**، تم رنگی **سبز و سفید**، برای اتصال کسب‌وکارها، فروشندگان، ارائه‌دهندگان خدمات و مشتریان در یک اکوسیستم امن و مدرن.

این پروژه یک سایت استاتیک HTML/CSS/JS خالص است؛ بدون فریم‌ورک، بدون فرآیند build، آماده برای هاست روی هر سرویس استاتیک (GitHub Pages, Netlify, Vercel, Nginx و ...).

---

## پیش‌نمایش سریع

```bash
# از ریشه‌ی پروژه
python3 -m http.server 8080
# سپس مرورگر را باز کنید:
http://localhost:8080/index.html
```

> باز کردن مستقیم فایل‌ها با دابل‌کلیک (`file://`) به دلیل بارگذاری فونت توصیه نمی‌شود؛ همیشه از یک سرور محلی استفاده کنید.

## نقشه‌ی صفحات

| فایل | توضیح |

## معماری فایل‌ها

```
assets/
  css/style.css          → کل دیزاین‌سیستم (توکن‌ها، تایپوگرافی، کامپوننت‌ها، ریسپانسیو)
  js/main.js             → تم روشن/تاریک، منوی موبایل، تب‌ها، ویش‌لیست، شمارنده‌ها، اسکرول
  svg/logo-mark.svg      → نماد لوگو (اتم سبز)
  svg/logo-mark-mono.svg → نماد تک‌رنگ (currentColor) برای حالت‌های خاص
  svg/logo-full.svg      → لوگوی کامل (نماد + وردمارک فارسی + انگلیسی)
  svg/icons.svg          → اسپرایت کامل آیکون‌های SVG (به‌صورت inline در هر صفحه تزریق شده)
```

آیکون‌ها به‌صورت اسپرایت `<symbol>` در ابتدای `<body>` هر صفحه inline شده‌اند و با `<use href="#icon-name">` فراخوانی می‌شوند — سریع‌ترین و سازگارترین شیوه‌ی استفاده از آیکون SVG در تمام مرورگرها.

## هویت بصری

### لوگو
نماد لوگو یک **اتم سبز** است: هسته‌ی مرکزی به‌همراه سه مدار الکترون، نماد علم، شبکه و اتصال — متناسب با مفهوم «ستاد» و فضای دیجیتال و علمی. لوگو در سه نسخه ارائه شده: رنگی (`logo-mark.svg`)، تک‌رنگ برای هر پس‌زمینه (`logo-mark-mono.svg` با `currentColor`)، و لوگوی کامل با وردمارک (`logo-full.svg`). هر سه SVG برداری و در هر اندازه (فاوآیکون تا بیلبورد) قابل‌استفاده‌اند و در هر دو حالت روشن و تاریک کار می‌کنند.

### رنگ — سبز و سفید
سیستم رنگی فلت با پایه‌ی سفید/خاکستری روشن و لهجه‌ی سبز برند:

| نقش | متغیر CSS | مقدار (روشن) |
|---|---|---|
| پس‌زمینه صفحه | `--bg` | `#F4F6F5` |
| سطح کارت | `--surface` | `#FFFFFF` |
| کادر/بوردر | `--border` | `#E6E9E7` |
| متن اصلی | `--text-1` | `#1A1D1B` |
| سبز برند (اصلی) | `--green-600` | `#149B3E` |
| سبز روشن | `--green-500` | `#1BB24B` |
| قرمز تخفیف | `--red-500` | `#E5484D` |
| کهربایی (ستاره‌ی امتیاز) | `--gold-500` | `#F0A020` |

حالت تاریک با `html[data-theme="dark"]` کاملاً بازتعریف شده (زغالی `#101311`، سطوح `#171A18`) و لهجه‌ی سبز روی آن می‌درخشد؛ با کلید تم در هدر (ذخیره در `localStorage`) قابل‌جابه‌جایی است.

### تایپوگرافی
فونت اصلی **Yekan Bakh** (فونت مورد استفاده در Basalam) در استک قرار دارد و در صورت نصب‌بودن روی سیستم/سرور به‌صورت خودکار استفاده می‌شود. به‌عنوان جایگزین رایگان و هم‌خانواده از نظر سبک، **Vazirmatn** (از Google Fonts) بارگذاری شده تا تجربه‌ی بصری همیشه یکدست و حرفه‌ای بماند:

```css
--font-fa: 'Yekan Bakh','YekanBakh','Vazirmatn','IRANSansX',Tahoma,sans-serif;
```

> برای استفاده‌ی رسمی از Yekan Bakh، فایل webfont لایسنس‌دار آن را به `assets/fonts` اضافه کرده و با `@font-face` در ابتدای `style.css` تعریف کنید؛ استک فونت به‌طور خودکار آن را در اولویت قرار می‌دهد.

### سبک بصری — فلت
طراحی کاملاً **فلت** است (نئومورفیسم حذف شده): کارت‌های سفید با کادر ۱ پیکسلی و سایه‌ی بسیار ملایم، گوشه‌های گرد، دکمه‌های تخت سبز، و هدر دو‌ردیفه به سبک Basalam (ردیف بالا: لوگو + نوار جستجوی برجسته + حساب/سبد؛ ردیف پایین: نوار دسته‌بندی‌ها).

## کامپوننت‌ها

دکمه‌ها (`.btn`, `.btn-primary`, `.btn-gold`, `.btn-ghost`, `.btn-icon`) · کارت‌ها (`.surface`) · کارت محصول (`.prod-card`) · کارت فروشنده (`.seller-card`) · نوار جستجو (`.search-bar`) · نوار دسته‌بندی (`.nav-main`) · تب‌بار (`.tabbar`) · فرم‌ها (`.field`) · جدول داشبورد (`.dtable`) · نشان وضعیت (`.status-chip`) · بنر تبلیغاتی (`.banner`) · حالت خالی/خطا (`.state-block`) · کشوی موبایل (`.mobile-drawer`) و ده‌ها کلاس کمکی دیگر.

همه‌ی کامپوننت‌ها **موبایل‌فرست و کاملاً ریسپانسیو** هستند (breakpoint در ۱۱۸۰px، ۹۸۰px و ۶۴۰px).

## یادداشت فنی

- سایت کامل RTL و بهینه برای فارسی است (`dir="rtl"` روی `<html>`).
- انیمیشن‌ها سبک و مبتنی بر `IntersectionObserver` (کلاس `.reveal`) و CSS transitions هستند؛ هیچ کتابخانه‌ی خارجی JS استفاده نشده.
- این یک دموی طراحی‌محور فرانت‌اند است؛ فرم‌ها، پرداخت و داده‌ها نمایشی (mock) هستند و برای اتصال به بک‌اند واقعی نیاز به توسعه‌ی API دارند.
